# Настройка OpenAI API Key

## ⚠️ ВАЖНО: НЕМЕДЛЕННО ЗАМЕНИТЕ СКОМПРОМЕТИРОВАННЫЙ КЛЮЧ!

Старый API ключ был опубликован в GitHub и должен быть удален!

## Шаг 1: Удалите старый ключ в OpenAI

1. Перейдите на https://platform.openai.com/api-keys
2. Войдите в свой аккаунт
3. Найдите ключ, который начинается с `sk-proj-3xFa4XSr...`
4. Нажмите кнопку "Delete" или "Revoke"
5. Создайте новый ключ, нажав "Create new secret key"
6. **Сохраните новый ключ** - он больше не будет показан!

## Шаг 2: Обновите локальную разработку

Откройте файл `.env` в корне проекта и замените старый ключ на новый:

```env
OPENAI_API_KEY=ваш_новый_ключ_здесь
```

## Шаг 3: Настройте Supabase Production

### Вариант А: Через веб-интерфейс

1. Перейдите на https://supabase.com/dashboard
2. Откройте свой проект
3. Перейдите в Settings → Edge Functions
4. Найдите раздел "Environment variables"
5. Добавьте/обновите переменную:
   - Name: `OPENAI_API_KEY`
   - Value: ваш_новый_ключ_здесь
6. Сохраните изменения

### Вариант Б: Через CLI

```bash
# 1. Авторизуйтесь в Supabase
supabase login

# 2. Привяжите проект (если еще не привязан)
supabase link --project-ref ваш-project-id

# 3. Установите секрет
supabase secrets set OPENAI_API_KEY=ваш_новый_ключ_здесь
```

## Проверка

После настройки проверьте, что все работает:

1. Локально: `pnpm dev` - проверьте дневной прогноз и интерпретацию снов
2. Production: откройте ваше приложение и проверьте те же функции
